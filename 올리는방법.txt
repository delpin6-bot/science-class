[GitHub 업로드 방법 - 모든 과학게임 몰입 모드(게임 화면 확대)]
1. 수업게임 저장소(GitHub Pages)에서 Add file > Upload files 클릭
2. 이 폴더의 HTML 26개를 모두 끌어다 놓기 (같은 이름은 덮어쓰기)
   - 게임 24개 : 오른쪽 아래에 '⛶ 몰입 모드' 버튼이 생겨요
   - 시작하기_수업게임서랍.html : 위쪽에 '🖥 몰입 모드 : 켬/끔' 버튼 (켜 두면 게임이 몰입 모드로 열려요)
   - 전자칠판_실행기.html : 게임을 전체화면·확대로 띄우는 실행기 (게임 몰입 모드에 꼭 필요해요)
3. Commit changes 후 1~2분 뒤 새로고침(Ctrl+F5)

[몰입 모드란?]
 - 게임 화면을 전체화면으로 크게 키워서 보여 줘요. 화면 크기에 맞춰 자동으로 확대되고(1920x1080 에서 150%),
   오른쪽 아래 조작 버튼의 ＋ － 로 더 키우거나 줄일 수 있어요.
 - 서랍으로 돌아가는 링크 등 학생 시선을 빼앗는 이동 메뉴는 몰입 모드에서 자동으로 숨겨져요.
 - 바람길 항해사는 자체 '게임 화면 확대' 모드가 이미 들어 있어요.
