[GitHub 업로드 방법 - 올인원 뱀주사위 레이스 (게임 서랍 + 과학수업 서랍 연동)]
1. 수업게임 저장소(GitHub Pages)에서 Add file > Upload files 클릭
2. 이 폴더의 HTML을 모두 끌어다 놓기 (같은 이름은 덮어쓰기)
   [꼭 필요한 4개]
   - 올인원_뱀주사위놀이.html     (개선된 게임)
   - 시작하기_수업게임서랍.html    (게임 카드 추가)
   - 통합_과학수업_서랍.html       (모든 차시 카드에 '🐍 뱀주사위' 버튼 추가)
   - 전자칠판_실행기.html          (몰입 모드에서 단원 설정이 유지되도록 수정)
   [함께 올리면 좋은 24개]
   - 나머지 게임 파일 : 몰입 모드 버튼이 단원 설정(?g=&u=)을 유지하도록 최신 코드로 교체
3. Commit changes 후 1~2분 뒤 새로고침(Ctrl+F5)

[연동 방식]
 - 과학수업 서랍의 각 차시 카드 > 🐍 뱀주사위 (그 단원) 버튼 → 해당 학년·단원으로 설정된 상태로 게임이 바로 열려요.
   (전자칠판 모드가 켜져 있으면 몰입 모드로 열려요)
 - 게임 주소에 직접 쓸 수도 있어요 : 올인원_뱀주사위놀이.html?g=중2&u=전기와 자기&teams=3
 - 서랍에 없는 단원은 자동으로 '전학년 종합'이 열려요.

[개선된 점]
 - 15개 전 단원이 자기 단원 문제를 사용 (이전에는 12개 단원이 전기와 자기 문제를 그대로 사용)
 - 전학년 종합 모드, 문제 반복 방지·보기 순서 섞기
 - 찬스 카드 뒤 다음 모둠이 건너뛰어지던 오류 수정, alert 창을 화면 알림으로 교체
 - 첫 오답은 힌트(오답 2개 제거)로 한 번 더 도전, 말이 한 칸씩 걸어서 이동, 뱀·사다리 그림 개선
 - 우승 후 모둠별 성적과 '다시 짚어 볼 개념(가장 많이 틀린 문제)' 자동 정리
