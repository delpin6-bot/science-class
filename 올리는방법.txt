[GitHub 업로드 방법 - 가상실험 상단 메뉴 제거(심플 디자인)]
1. 수업게임 저장소(GitHub Pages)에서 Add file > Upload files 클릭
2. 이 폴더의 HTML 52개를 모두 끌어다 놓기 (같은 이름은 덮어쓰기)
3. Commit changes 후 1~2분 뒤 새로고침(Ctrl+F5)

[바뀐 점]
 - 가상실험 화면 맨 위의 서랍 이동 메뉴(통합과학 / 가상실험 / 수업게임)를 없애 학생 시선이 실험에만 모이게 했습니다.
 - 탐구 활동지 · 처음으로 · 원리 설명 · QR 버튼은 그대로 남겼습니다.
 - 서랍으로 돌아갈 때는 전자칠판 모드의 오른쪽 아래 '서랍' 버튼 또는 브라우저의 뒤로가기를 쓰세요.
