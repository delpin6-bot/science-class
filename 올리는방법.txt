[GitHub 업로드 방법 - 전자칠판 모드(전체화면 보기) + QR 크게 보기]
1. 수업게임 저장소(GitHub Pages)에서 Add file > Upload files 클릭
2. 이 폴더의 HTML 13개를 모두 끌어다 놓기 (같은 이름은 덮어쓰기)
   - 전자칠판_실행기.html   (새 파일 : 가상실험을 어두운 배경·큰 버튼으로 전체화면에 띄우는 실행기)
   - 연주시차.html          (다크 네이비 테마·큰 글자·우측 조작 독·심플 보기로 개편)
   - 가상실험실_서랍.html / 통합_과학수업_서랍.html   (상단 '🖥 전자칠판 모드' 버튼 추가)
   - 시작하기_수업게임서랍.html 외 QR 창이 있는 파일들 (QR '⛶ 크게 보기' 버튼 추가)
3. Commit changes 후 1~2분 뒤 접속 : https://계정명.github.io/저장소명/가상실험실_서랍.html

* 모든 파일은 같은 폴더에 둘 것 / 전자칠판_실행기.html은 반드시 함께 올려야 서랍의 전자칠판 모드가 동작합니다.
