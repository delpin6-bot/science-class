[탐구 활동지] 마찰시키면 왜 전기를 띨까? (마찰전기와 유전 분극)

2학년 반 번 이름:
⚡ 탐구 1: 고양이 털과 고무 풍선의 마찰 및 전하 이동 전자의 이동
1) 마찰 전 고양이와 풍선의 전하 상태:
• 마찰 전 고양이와 풍선은 (+) 전하의 양과 (-) 전하의 양이 같아서 전기적으로 ( ) 상태이다.
2) 고양이 털에 풍선을 문질렀을 때 일어나는 입자의 이동:
• 서로 다른 두 물체를 마찰하면 털가죽에서 고무 풍선으로 ( )가 이동한다.
• [고양이 털]: 전자를 잃었으므로 [ ( ) 전하 ]로 대전된다.
• [고무 풍선]: 전자를 얻었으므로 [ ( ) 전하 ]로 대전된다.
• 주의: 원자핵은 무거워서 이동하지 않으며, 오직 가벼운 ( )만 이동한다!
🪜 탐구 2: 전자를 잃기 쉬운 순서 (대전열 사다리) 대전열 규칙
1) 대전열: 전자를 잃기 쉬운 순서대로 나열한 것
(+) 전자를 잃기 쉬움 [ 털가죽 — 유리 — 명주 — 나무 — 고무 — 플라스틱 ] 전자를 얻기 쉬움 (-)
마찰시킨 두 물체 전자를 잃는 물질 (+) 전자를 얻는 물질 (-) 두 물체 사이에 작용하는 힘
털가죽과 고무 풍선 털가죽 고무 풍선 서로 끌어당기는 힘 (인력)
유리 막대와 명주 헝겊 유리 막대 명주 헝겊 서로 끌어당기는 힘 (인력)
🧱 탐구 3: (-)로 대전된 풍선이 중성인 벽에 달라붙는 까닭 유전 분극
Q. 전기가 통하지 않는 부도체인 벽에 문지른 풍선을 가져가면 찰싹 붙는 까닭을 서술하시오.
• 중성인 벽에 (-) 대전된 풍선을 가까이 가져가면, 벽 내부 원자의 전자들이 척력을 받아 ( )으로 살짝 밀려난다.
• 그 결과 풍선과 가까운 벽 표면에는 ( ) 전하가 상대적으로 가깝게 배치되는 ( ) 현상이 일어난다.
• 풍선과 벽 표면의 (+) 전하 사이의 인력이 척력보다 더 강하기 때문에 풍선이 벽에 달라붙는다.
💡 생활 속 마찰전기 현상 2가지를 쓰시오:
1) 빗으로 머리를 빗을 때 머리카락이 빗에 달라붙거나 사방으로 뻗친다.
2) 스웨터를 벗을 때 찌릿찌릿 소리가 나거나 불꽃이 튄다. (비닐 랩이 그릇에 붙는 현상)
