📖 사용 방법

  1. 이 폴더 전체를 교실 PC나 USB에 복사하세요. (파일 하나만 옮기면 다른 자료로 이동하지 못해요)
  2. 시작하기.html을 더블클릭 → 크롬 또는 엣지로 열려요. 인터넷은 필요 없어요.
  3. 서랍에서 학년 → 단원 → 차시를 눌러 자료를 열어요. 모든 자료는 새 창으로 열려요.
  4. 파일 이름과 폴더 위치는 바꾸지 마세요. 자료끼리 이름으로 서로 연결되어 있어요.
  5. 가상실험은 서랍에서 열면 전자칠판 모드(전체화면 실행기)로 열려요. 처음 한 번 ▶ 전체화면으로 시작을 누르고, 오른쪽 아래 버튼으로 확대·축소·QR을 쓰세요. (서랍 위쪽 🖥 전자칠판 모드 버튼으로 켜고 끌 수 있어요)
  6. QR 창의 ⛶ 크게 보기를 누르면 교실 뒤에서도 찍을 수 있는 큰 QR이 전체화면으로 나와요.
📱 QR 코드 버튼은 GitHub 같은 인터넷 주소가 있어야 학생 휴대폰으로 열려요. 오프라인(내 PC 파일)에서는 주소를 직접 붙여 넣어 QR을 만들 수 있어요.
💾 즐겨찾기(★)와 오답 기록은 이 컴퓨터의 브라우저에 저장돼요. 다른 PC·다른 브라우저에서는 처음부터 시작해요.
