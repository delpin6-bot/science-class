# 과학수업 서랍 (중1~중3 과학 수업 게임 · 자바실험실)

미래엔 중학교 과학 교과서 단원·차시에 맞춘 **수업 게임 22종**과 **가상실험(자바실험실) 50종**을 모은 정적 웹사이트입니다.
설치나 로그인 없이 브라우저에서 바로 실행되며, 학생들은 휴대폰·아이패드로 **QR 코드를 찍어 해당 차시로 바로 접속**할 수 있습니다.

| 👩‍🏫 교사용 오답 대시보드 | `교사대시보드.html` |

## GitHub Pages로 공개하기
1. 이 저장소의 **Settings → Pages**로 갑니다.
2. **Build and deployment → Source: Deploy from a branch**, **Branch: `main` / `/ (root)`** 를 고르고 **Save**.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소가 생깁니다.
4. `https://<아이디>.github.io/<저장소이름>/배포_점검.html` 을 열어 **[점검 시작]** → 모든 파일이 정상인지 확인합니다.
5. 그 주소로 **QR코드 만들기**를 열면 사이트 주소가 자동으로 들어가고, 차시별 QR을 띄우거나 인쇄할 수 있습니다.

> ⚠ 저장소는 **Public(공개)** 이어야 무료로 GitHub Pages를 쓸 수 있습니다.

## 폴더 구조
```

```

## 주요 기능
- 모든 게임: 학년 → 대단원 → 중단원·차시 메뉴와 검색, 상단 서랍 이동 버튼
- 효과음: 정답(Victory_Lap)·오답(Prompt_Attention)·큰 축하(Top_of_the_Board)·배경음악
- 오답 피드백: 게임 종료 후 "다시 볼 개념(오답 TOP 3)", 교사용 오답률 대시보드
- 순위표: 개인·모둠 점수 기록(정확도 50% 미만은 순위 제외)

## 알아 둘 점
- 학생용 활동지에는 정답이 없습니다. 교사용 파일(`…_교사용.html`)은 내용이 암호화되어 있어 교사 암호로만 열립니다. **암호를 이 저장소나 공개 문서에 적지 마세요.**
- 학생 기록(순위표·오답)은 **각 기기 브라우저에만 저장**되고 서버로 보내지지 않습니다.
- 파일 이름을 바꾸면 서랍 링크와 이미 인쇄한 QR이 맞지 않을 수 있습니다.
- 한글 파일명은 표준 방식(NFC)으로 맞춰 두었습니다. 맥에서 수정 후 다시 올릴 때 파일명이 바뀌지 않도록 주의하세요.
