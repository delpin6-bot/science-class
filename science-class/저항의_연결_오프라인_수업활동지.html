1) 저항을 직렬로 연결할 때의 물리적 변화:
• 저항을 직렬로 연결하는 것은 도선의 ( )가 길어지는 것과 같다.
• 합성 저항 (R): 각 저항의 합과 같으므로 저항을 연결할수록 전체 저항은 ( ). (R = R₁ + R₂)
• 회로 전체 전류 (I): 전체 저항이 커지므로 회로에 흐르는 전류의 세기는 ( ).
🔀 탐구 3: 저항의 병렬연결 (요금소 차선이 나란히 늘어날 때) 병렬연결
2) 저항을 병렬로 연결할 때의 물리적 변화:
• 저항을 병렬로 연결하는 것은 도선의 ( )이 넓어지는 것과 같다.
• 합성 저항 (R): 통로가 여러 갈래로 분산되므로 저항을 병렬로 연결할수록 전체 저항은 ( ). (1/R = 1/R₁ + 1/R₂)
• 회로 전체 전류 (I): 전체 저항이 작아지므로 전원에서 공급하는 전체 전류의 세기는 ( ).
