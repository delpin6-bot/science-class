⚡ 탐구 1: 대전체를 금속판에 가까이 가져갈 때 (정전기 유도) 금속박 벌어짐
1) (-) 대전체를 금속판에 가까이 가져갔을 때:
• 금속판의 자유 전자들이 ( )을 받아 아래쪽 금속박으로 밀려 내려간다.
• [금속판]: 전자를 잃어 [ ( ) 전하 ] / [금속박]: 전자를 얻어 [ ( ) 전하 ]로 대전된다.
• 결과: 두 장의 금속박이 서로 같은 (-) 전하를 띠므로 척력에 의해 ( ).
2) (+) 대전체를 금속판에 가까이 가져갔을 때:
• 금속박의 자유 전자들이 ( )을 받아 위쪽 금속판으로 끌려 올라간다.
• [금속판]: [ ( ) 전하 ] / [금속박]: [ ( ) 전하 ] $\rightarrow$ 금속박이 ( ).
👉 탐구 2: 대전체를 댄 상태에서 금속판에 손가락을 댈 때 (접지) 금속박 오므라듦
Q1. (-) 대전체를 가까이 댄 채 손가락을 금속판에 대면 금속박이 오므라드는 까닭은?
• (-) 대전체로부터 척력을 받던 금속박의 전자들이 ( )을 통해 밖으로 빠져나가기 때문이다.
• 전자가 빠져나간 금속박은 전기적으로 ( )이 되어 척력이 사라져 오므라든다.
🔄 탐구 3: 검전기를 (+) 또는 (-)로 영구 대전시키는 올바른 순서 순서가 생명
Q2. 검전기를 (+) 전하로 영구 대전시키는 올바른 실험 절차를 순서대로 나열하시오.
[단계 ( 1 )]: ( ) 대전체를 금속판에 가까이 가져간다. (금속박 벌어짐)
[단계 ( 2 )]: 대전체를 댄 상태에서 금속판에 손가락을 댄다. (전자가 손가락으로 빠져나가 금속박 오므라듦)
[단계 ( 3 )]: [ ( )을 먼저 뗀다! ] (빠져나간 전자가 다시 못 돌아오게 차단)
[단계 ( 4 )]: 대전체를 멀리 치운다. $\rightarrow$ 검전기 전체는 [ ( ) 전하 ]로 대전되어 금속박이 다시 벌어진다!
🕵️ 탐구 4: 이미 (-)로 대전된 검전기를 이용한 미지의 대전체 판별 전하 판별
• 이미 (-)로 대전되어 벌어져 있는 검전기에 미지의 대전체 X를 접근시켰더니 금속박이 더 벌어졌다!
$\rightarrow$ 대전체 X의 전하는? [ ( ) 전하 ] (이유: 금속판의 전자가 금속박으로 더 밀려 내려갔기 때문)
• 만약 금속박이 오므라들었다면 대전체 X의 전하는? [ ( ) 전하 ]
