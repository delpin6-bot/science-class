[탐구 활동지] 백열전구는 왜 뜨거워지고 빛을 낼까? (저항의 열작용)

2학년 반 번 이름:
⚡ 탐구 1: 회로 스위치 On/Off에 따른 도체 내부 전자의 운동 전자의 운동
1) 스위치가 열려 있을 때 (OFF):
• 전압이 걸리지 않으므로 자유 전자들은 모든 방향으로 ( )을 하여 순수한 전류의 흐름이 없다.
2) 스위치를 닫았을 때 (ON):
• 전지에 의해 도체 내부에 전기장이 형성되어, 자유 전자들이 전기력을 받아 전지의 ( )극에서 ( )극 방향으로 일제히 ( )한다.
🧱 탐구 2: 전기 저항이 생기는 까닭과 열에너지 발생 미시적 충돌
Q1. 도체 내부에서 '전기 저항'이 나타나는 미시적 원인은 무엇인가?
• 이동하는 자유 전자들이 도체 내부의 고정된 ( )와 끊임없이 ( )하여 흐름을 방해받기 때문이다.
Q2. 전자가 원자와 충돌할 때 열이 발생하는 까닭은?
• 전자의 운동 에너지가 원자에 전달되어 원자의 ( )이 격렬해지기 때문이다.
• 원자의 진동이 활발해질수록 도체의 온도가 상승하여 열이 발생한다. (줄열, 전기 에너지 $\rightarrow$ 열에너지)
💡 탐구 3: 백열(Incandescence) 현상과 전압의 영향 빛 에너지 전환
Q3. 백열전구 필라멘트가 빛을 내는 까닭과 전압을 높였을 때의 변화를 서술하시오.
• 얇은 텅스텐 필라멘트에서 온도가 수천 ℃(2000~2500℃)까지 치솟으면 열복사에 의해 ( )을 방출한다.
• 전압을 1.5V에서 6.0V로 높이면: 회로의 전류가 ( ) $\rightarrow$ 전자의 이동 속도와 충돌 횟수 ( ) $\rightarrow$ 온도가 더 ( )하여 전구가 ( ).
🔍 탐구 4: 구리 도선은 왜 안 뜨겁고, 필라멘트만 뜨거울까? 저항의 크기 비교
• 구리 도선: 굵고 저항이 ( ) 전자와의 충돌이 적어 열이 거의 나지 않는다.
• 텅스텐 필라멘트: 매우 가늘고 길어서 저항이 ( ) 때문에 좁은 길목에서 전자와 원자의 충돌이 집중되어 고열과 빛을 뿜어낸다.
교사용 가이드

🏃 활동 1: [인간 도체 릴레이 (저항과 충돌 시뮬레이션)]

1. 모의실험 세팅

  • 교실 복도 또는 앞쪽에 학생 6명이 일렬로 서서 '고정된 원자핵' 역할을 합니다 (발을 바닥에 붙임).
  • 학생 4명은 파란 조끼를 입은 '자유 전자' 역할을 맡습니다.

2. 진행 절차

  1. [스위치 OFF]: 전자 학생들이 제자리에서 무작위로 서성이며 천천히 멥니다.
  2. [스위치 ON - 저전압]: 전자 학생들이 일정한 속도로 원자핵 사이를 빠져나갑니다. 살짝 부딪힐 때마다 원자핵 학생들은 양팔을 살살 흔듭니다 (미세한 열진동).
  3. [스위치 ON - 고전압]: 전자들이 빠르게 통과하며 원자핵과 쾅쾅 충돌합니다. 원자핵 학생들은 격렬하게 몸을 흔들며 "앗 뜨거!"를 외칩니다 (열작용과 백열 발광 표현).
교사용 가이드

✏️ 활동 2: [샤프심 백열전구 만들기 실물 실험 가이드]

1. 실험 준비물

0.5mm 샤프심(B 또는 2B), 1.5V 건전지 4개(직렬 홀더 6V) 또는 9V 사각 건전지, 악어 집게 전선 2개, 투명 유리병(또는 내열 비커), 점토.

2. 실험 방법 및 안전 수칙

  1. 점토 위에 악어 집게 2개를 2cm 간격으로 세우고, 샤프심을 집게 사이에 가로질러 고정합니다.
  2. 투명 유리병을 거꾸로 덮어 외풍을 막습니다. (유리병 내부 산소가 소모되며 타는 것을 지연시킴)
  3. 전선 스위치를 연결하면, 샤프심 내부 저항의 열작용으로 수초 내에 붉게 달아오르다 눈부신 백열 빛을 방출합니다!
  4. 안전 주의: 샤프심이 매우 뜨거우므로 직접 손을 대지 않도록 지도하며, 실험 후 집게 전선을 즉시 분리합니다.
