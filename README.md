# 🔬 중학교 과학 수업 서랍

중1 · 중2 · 중3 과학 수업을 위한 **단일 HTML 모음**입니다. 서버·설치 없이 GitHub Pages에 올리면 바로 쓸 수 있고, 학생 휴대폰·태블릿·전자칠판 어디서든 열립니다.

| 서랍 | 파일 | 내용 |
|---|---|---|
| 📚 통합 과학수업 서랍 | `통합_과학수업_서랍.html` | 차시별(56개) 가상실험 · 활동지 · 마인드맵 · 개념 격추 · 뱀주사위 바로가기 |
| 🧪 가상실험실 서랍 | `가상실험실_서랍.html` | 학년 > 단원 > 차시로 찾는 가상실험·활동지 72종 |
| 🎮 수업 게임 서랍 | `시작하기_수업게임서랍.html` | 과학 게임 26종 (몰입 모드 지원) |
| 🚀 동기유발 서랍 | `동기유발_서랍.html` | 수업 시작 3분 도입 30세트 (오개념 저격수 · 밸런스 게임 · 사이언스 CSI · 20초 줌인 · What-If) |
| 🖥 전자칠판 실행기 | `전자칠판_실행기.html` | 가상실험·게임을 전체화면으로 확대해 여는 도구 (서랍에서 자동 사용) |

처음 화면은 `index.html` 입니다.

## 1. GitHub Pages로 공개하기

1. GitHub에서 **새 저장소**를 만듭니다. (예: `science-lab`)
2. 이 꾸러미의 파일을 모두 올립니다. (아래 2번 참고)
3. 저장소 **Settings → Pages → Build and deployment**
   - Source : `Deploy from a branch`
   - Branch : `main` / `(root)` → **Save**
4. 1~2분 뒤 `https://계정명.github.io/저장소명/` 으로 열립니다.
5. 각 화면의 **📱 QR** 버튼에 위 주소(또는 파일 주소)를 한 번 붙여 넣으면 학생용 QR이 만들어집니다.

> 폴더 없이 **한 곳(루트)에 평평하게** 올리는 구조입니다. 파일 이름이 서로를 가리키므로 이름을 바꾸거나 폴더로 옮기지 마세요. (폴더로 나눈 구성은 인터넷이 없는 교실용 오프라인 꾸러미에만 있습니다.)

## 2. 올리는 방법

**웹에서 올릴 때** : 한 번에 올릴 수 있는 파일이 **100개까지**라서 두 번에 나눠 올립니다.
`GitHub_웹업로드_1차.zip` 압축을 풀고 파일과 `sounds` 폴더를 끌어다 놓기 → *Commit changes* → `GitHub_웹업로드_2차.zip` 도 같은 방법으로 올립니다.

**git을 쓸 때** : `GitHub_저장소_전체.zip` 압축을 푼 폴더에서
```bash
git init && git add . && git commit -m "과학 수업 서랍"
git branch -M main
git remote add origin https://github.com/계정명/저장소명.git
git push -u origin main
```

## 3. 고치고 새로 올리기

- 같은 이름의 파일을 다시 올리면(덮어쓰기) 1~2분 뒤 반영됩니다. 반영이 안 보이면 `Ctrl + F5`.
- 서랍에 보이는 카드(제목·설명·차시)는 각 서랍 HTML 안의 자료 배열에서 고칩니다.
- 숫자가 바뀔 수 있는 자료(예: `행성의_특징과_태양계_형성.html` 의 위성 수)는 파일 안의 `const PL=[...]` 한 곳에서 고치면 모든 화면에 반영됩니다.

## 4. 직접 넣어 주셔야 하는 파일

- `골든벨.html`, `거짓말탐지기.html`, `낱말퍼즐생성기.html` : 서랍의 버튼이 이미 이 이름을 가리키고 있어, 같은 위치(루트)에 넣으면 바로 연결됩니다.
- `sounds/` 폴더의 보조 스크립트 (`sounds/README.md` 참고).
- `45분_모듈러_수업서랍.html` : 개념 격추 상단 메뉴의 「45분 모듈러」가 가리키는 파일입니다.

## 5. 일부러 뺀 것

- **교사용 정답지**(`교사용_정답지.zip` 등)는 학생이 볼 수 있는 공개 저장소에 올리지 않도록 뺐습니다. 교사 PC에서만 쓰거나 *비공개* 저장소에 두세요.
- 이전의 `수업도입_동기유발_5대게임.html` 은 **동기유발 서랍**으로 대체되었습니다. 저장소에 남아 있다면 삭제해도 됩니다.
- 예전 이름의 `자바실험실_서랍*.html` 3개는 용량이 작은 **안내 이동 파일**입니다. (예전 링크가 가상실험실 서랍으로 연결되도록 남겨 둠)

- **교과서 그림이 들어 있는 파일** : `호르몬의_조절_작용_교과서그림판.html`, `항상성_유지.html`, `염색체_DNA_유전자.html` 에는 교과서 그림(내분비샘, 신경계, 부교감 신경, 혈당 조절, 당뇨병 만화)이 들어 있어요. 저작권은 출판사에 있고, 이 저장소는 **개인 수업용**으로만 사용합니다. 다른 사람에게 재배포하거나 상업적으로 쓰지 마세요.
